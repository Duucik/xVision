# xVision ITAA

Хоккейная видеоаналитика: нарезка клипов, теги, рисование, «Позиция», Тренерская.

**Скачать:** раздел [Releases](../../releases/latest) → `xVision-ITAA-Setup-<версия>.exe`.
Установленная программа обновляется сама.

Программа работает по ключу. Ключ выдаёт автор. В репозитории — только открытая половина ключа
(`license/public.key`), выдать ключ по ней нельзя.
